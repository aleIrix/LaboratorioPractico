# Laboratorio Práctico - Taller Colaborativo de GIT/GITHUB

Proyecto colaborativo para la asignatura Desarrollo de Software V (UTP).
Es la continuación del taller práctico de HTML y CSS: cada integrante tiene
una página personal con dos tarjetas (una de presentación y otra sobre un
videojuego, película o tema de interés), y el trabajo se realizó aplicando
control de versiones con Git y GitHub.

## Estructura del proyecto
```
LaboratorioPractico/
├── HTML/         -> Index.html, persona1.html, persona2.html, persona3.html
├── CSS/          -> style.css
├── Imagenes/     -> fotos y recursos gráficos usados en las páginas
└── README.md
```

## Cambios más relevantes del proyecto
- Creación del repositorio y estructura inicial de carpetas (Coordinador).
- Creación de la tarjeta de presentación de cada integrante (persona1,
  persona2, persona3) en ramas independientes.
- Fusión (merge) de las ramas `persona2` y `Persona3` a `main` mediante
  Pull Requests.
- Reorganización del proyecto en carpetas separadas para HTML, CSS e
  imágenes, cumpliendo con la estructura solicitada.
- Ampliación de cada página personal con una segunda tarjeta referente a un
  videojuego, película o tema de interés de cada integrante.

## Cómo ejecutar el proyecto
Abrir `HTML/Index.html` en cualquier navegador. Desde ahí se puede navegar a
la página de cada integrante mediante el menú superior.
